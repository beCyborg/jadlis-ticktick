# TickTick из Claude Code: короткая команда — и задача на месте

Скилл `/jadlis-ticktick:ticktick` ведёт задачи, привычки и фокус в TickTick через официальный
MCP TickTick (сервер инструментов от самого TickTick). Ты пишешь коротко: «что на сегодня»,
«добавь купить молоко завтра», «чекин медитация». Скилл выбирает нужный инструмент и отвечает
в 1–3 строки.

## Что умеет

- Показывает задачи на сегодня и выполненное за период.
- Добавляет одну задачу или список задач. Даты вроде «завтра», «пн», «12.08» переводит сам.
- Завершает задачу или закрывает её как «не буду делать».
- Переносит задачу в другой список или на другую дату.
- Отмечает привычки и показывает чек-ины.
- Показывает время фокуса.
- Ищет задачи по названию.

Скилл знает ловушки API TickTick, которые не описаны в документации. Например, задачи «на весь
день» хранят даты двумя способами. Поэтому скилл сравнивает даты только в твоём часовом поясе.
Часовой пояс он берёт из настроек TickTick, а не задаёт сам.

## Как поставить

Нужен Claude Code и аккаунт TickTick.

```
claude plugin marketplace add https://gitlab.com/beCyborg/jadlis-hub.git
claude plugin install jadlis-ticktick@jadlis
claude plugin list
```

Первая команда добавляет маркетплейс, вторая ставит плагин. Удалить:
`claude plugin uninstall jadlis-ticktick@jadlis`.

**Первый вход.** Плагин подключает сервер `https://mcp.ticktick.com/`. При первом вызове
Claude Code откроет страницу входа TickTick (OAuth — вход через сайт TickTick, без пароля в
Claude Code). Если окно не открылось, набери `/mcp`, выбери `plugin:jadlis-ticktick:ticktick` и
нажми вход.

**Если сервер TickTick у тебя уже есть.** Если ты раньше добавил свой MCP-сервер TickTick
(например, `claude mcp add`), плагин добавит второй такой же. Скилл работает с любым из них.
Лишний отключи в `/mcp`.

**Личный профиль — по желанию.** В профиле можно описать, в какой список класть какие задачи,
какие метки ставить и как менять списки в начале квартала. Без профиля новые задачи идут в
Inbox, а при неясности скилл спрашивает. Создай файл, например `~/ticktick-profile.md`, и укажи
путь к нему — в сессии через `/config` или командой:

```
echo '{"PROFILE_PATH":"~/ticktick-profile.md"}' | claude plugin configure jadlis-ticktick@jadlis --values-stdin
```

Образец — [assets/profile.example.md](assets/profile.example.md).

## Как пользоваться

Набери в Claude Code:

```
/jadlis-ticktick:ticktick что на сегодня
```

Или просто скажи своими словами:

- «добавь позвонить в банк завтра в 10»
- «добавь: молоко; хлеб; батарейки» — три задачи одним вызовом
- «готово отчёт»
- «перенеси ремонт велосипеда на субботу»
- «чекин вода 3»
- «сколько я фокусился на этой неделе»
- «что сделано за вчера»

Пример ответа:

```
Сегодня 4 задачи:
⬜ 🔴 Отправить отчёт — Работа, 11:00
⬜ ⚪ Купить молоко — Inbox
```

## Границы

- Работает только через официальный MCP TickTick. Если инструмента нет на сервере, скилл так и
  скажет.
- Календарь не охвачен: события календаря скилл не читает и не создаёт.
- «Завершить все задачи списка» скилл делает только после твоего прямого подтверждения: это
  действие нельзя отменить.
- Фото и вложения задач API не отдаёт. Скилл подскажет обходной путь.
- Плагин бесплатный, ключи API не нужны: вход идёт через OAuth TickTick.
- Плагин сам ничего не хранит: задачи идут напрямую между Claude Code и сервером TickTick.
  Политика конфиденциальности TickTick: https://ticktick.com/about/privacy
