# Профиль TickTick

Скилл читает этот файл один раз за сессию. Правила отсюда заменяют умолчания скилла.
Подтверждения опасных действий профиль не отменяет.

## Списки и маршрутизация

Куда класть новую задачу, если я не назвал список сам:

| Если задача про… | Список |
|---|---|
| работу, клиентов, отчёты | Работа |
| быт, покупки, ремонт, платежи | Дом |
| врачей, анализы, тренировки | Здоровье |
| всё остальное | Inbox |

- Если сомневаешься между двумя списками — спроси одним вопросом.
- В Inbox клади только то, что не подходит никуда, или по команде «в инбокс».

## Метки

- Живые метки: `срочно`, `звонок`. Новых меток не создавай.
- Метку `звонок` ставь, если задача начинается со слов «позвонить», «созвон».

## Чеклисты

- Мелкие бытовые дела добавляй пунктом в задачу-чеклист «Мелочи по дому» в списке Дом,
  а не отдельной задачей.
- Пункты внутри чеклиста идут блоками: пункт-заголовок `— ПОКУПКИ —`, под ним пункты блока.

## Смена квартала

Если списки у тебя повторяют цели квартала, опиши здесь порядок смены. Пример:

1. Сними снапшот: `list_projects` и открытые задачи каждого списка старого квартала.
2. По каждой открытой задаче спроси меня: перенести в новый список, завершить,
   «не буду делать» или удалить. Удаляй по одной.
3. Когда открытых задач не осталось, архивируй старые списки: `update_project {closed: true}`.
4. Создай списки нового квартала, по одному на цель. Имя — эмодзи и короткое название цели.
5. Выполненные цели прошлого квартала не переноси.
